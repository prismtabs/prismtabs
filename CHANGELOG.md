# PrismTabs Changelog

## [Unreleased]

### Added

- Chrome-style colour groups for editor tabs: right-click a tab for the swatch popup, pick one of
  8 preset colours to start a new group and name it, or add the tab to an existing group. Rename
  and recolour from "Manage Groups…". Unlimited groups, and assignments persist across restarts
  and survive file renames/moves — free forever.
- **Paid** (30-day free trial on new installs, then a subscription): the "Tab Groups" tool window
  listing every group with its colour and member count; hide/show to close a group's tabs and
  remember them, then reopen them together later; marking a group active so files opened while
  it's active join it automatically; and a custom palette editor under
  **Settings | Tools | PrismTabs**.
